# 主要行为认定与法律依据对照表

**适用案例：高校教授陈某将登记于学校名下的轮毂制造工艺专利作价入股创业公司。**

本表是《职务发明权属界定与科技成果转化管理分析报告》的独立配套文档，专门回答“主要行为如何认定、认定依据哪些条款”。表内结论以题设事实为基础；对任务、设备作用、研究生贡献、校内制度等尚未查明的事项，明确列出认定条件，不将待核实事实直接认定为违法。

**版本说明：**本案研发及交易发生于2019年至2023年。下表“原《专利法实施细则》”指2010年修订版本：原第12条对应现行第13条，原第13条对应现行第14条。现行细则自2024年1月20日起施行。对2022年授权奖励，不追溯适用现行更高的默认奖金标准。

## 一、研发性质、专利权属及发明人权益

| 主要行为或争议事项 | 本案认定及适用条件 | 法律条款及对应规则 |
| --- | --- | --- |
| 1. 将轮毂制造工艺认定为职务发明 | 现有事实较强地支持职务发明，应原则上按学校持有的职务成果处理；仍须核查任务、资源使用和有效权属协议。“执行单位任务”与“主要利用单位物质技术条件”任一成立即可，不要求二者同时成立。 | 《专利法》第6条第1款：规定两项选择性认定标准，并将职务发明的申请权、授权后的专利权归于单位。原《专利法实施细则》第12条：细化任务和物质技术条件。《民法典》第847条第2款：规定职务技术成果的对应认定标准。 |
| 2. 陈某的研发属于“执行学校任务” | 如研发属于其受聘科研职责、学校承担的项目或学校交办的其他技术攻关任务，可认定满足任务标准。不能只因其是教授，就推定其所有发明均归学校；应查岗位合同、任务书、项目合同和科研记录。 | 《专利法》第6条第1款；原《专利法实施细则》第12条第1款第（一）、（二）项：分别规定本职工作中的发明、单位交付的本职工作之外任务所产生的发明。现行对应为第13条第1款第（一）、（二）项。 |
| 3. 使用3D打印机、材料测试仪器属于“主要利用学校物质技术条件” | 设备属于学校物质技术条件，但“使用过”不等于“主要利用”。若设备反复试验、参数优化对形成核心工艺具有实质作用，可支持认定；若完整方案形成后仅进行一般验证、测试，则不能据此当然认定。 | 《专利法》第6条第1款；原《专利法实施细则》第12条第2款：资金、设备、原材料、未公开技术资料等属于物质技术条件。《最高人民法院关于审理技术合同纠纷案件适用法律若干问题的解释》（2020年修正）第3条、第4条：解释相关条件及实质影响，并区分成果完成后的验证、测试等情形；用于技术成果审查参照，专利权属仍依专利规定具体判断。 |
| 4. 陈某以“个人学术积累”“私人招募学生”为由要求改称合作研发 | 个人积累可以证明创造性贡献，但不能单独排除职务发明；私人招募也不能直接形成学校与个人之间的合作开发关系。如确有合法有效的资源型权属协议或真实合作安排，应审查协议及研发事实，不能由陈某单方事后更名。 | 《专利法》第6条第1款、第3款：分别规定职务归属及利用单位物质技术条件完成发明时的合同约定规则。第8条：规定合作、委托完成发明的归属规则，但须以真实合作、委托关系及有效协议为基础，不能凭“合作”称谓排除第6条审查。 |
| 5. 两名研究生是否构成共同发明人 | 对关键工艺、实质性技术特征作出创造性贡献的，应认定为共同发明人；仅按既定方案打印、测试或整理数据者，不当然具有发明人资格。应对照专利权利要求、实验记录及各人提出的技术方案逐项认定。 | 原《专利法实施细则》第13条、现行第14条：发明人须对实质性特点作出创造性贡献；仅组织、提供条件便利或从事辅助工作者不是发明人。上述技术合同司法解释第6条：进一步解释创造性贡献的认定。 |
| 6. 陈某、研究生主张署名、更正遗漏发明人 | 陈某享有真实发明人署名权；研究生若属于共同发明人，也享有署名权。学校持有专利、导师身份和是否被正式指派，均不当然排除实际发明人的署名。署名与专利财产权归属应分别判断。 | 《专利法》第16条第1款：发明人有权在专利文件中写明自己是发明人。《民法典》第849条：完成技术成果的个人享有在相关文件上表明完成者身份及取得荣誉证书、奖励的权利。该署名规则不是《专利法》第15条或《民法典》第848条。 |
| 7. 陈某及共同发明人主张授权奖励 | 职务发明获得授权后，学校负有奖励义务。对2022年授权，如无约定、又无依法制定的相关制度，应适用当时“一项发明专利不少于3000元、授权公告起三个月内支付”的默认规则；不是每名发明人各3000元。 | 《专利法》第15条第1款：规定单位的授权奖励义务。原《专利法实施细则》第77条第1款：规定当时无制度、无约定时的奖励金额和期限。现行第93条的4000元默认标准不直接追溯用于本案2022年授权。 |
| 8. 陈某及研究生主张转化报酬或奖励 | 职务发明人依法享有合理报酬；对完成、转化成果作出重要贡献的人员，应依法律及有效制度、协议分配。符合条件的研究生不能仅因不是教职工被排除；一般辅助参与者也不当然与发明人平均分配。授权奖金不能替代转化报酬。 | 《专利法》第15条第1款、第2款：合理报酬及股权、期权、分红等激励。《促进科技成果转化法》第44条、第45条：规定重要贡献人员的奖励报酬及最低标准。 |
| 9. 少量使用学校资源或完全个人研究的权属 | 少量、辅助性使用资源，不当然认定职务发明；应再核查任务标准、资源作用及协议。真正不执行学校任务、也未主要利用学校条件的个人发明，权利归个人；学校不能强制收归校有或无依据提成。 | 《专利法》第6条第2款、第3款：非职务发明归个人及资源利用中的权属约定；第7条：不得压制非职务发明申请。《民法典》第848条：非职务技术成果的使用权、转让权归完成者个人。 |

## 二、专利作价入股、交易效力与收益分配

| 主要行为或争议事项 | 本案认定及适用条件 | 法律条款及对应规则 |
| --- | --- | --- |
| 10. 陈某未经学校授权，以学校专利作为个人出资 | 发明人身份不等于专利处分权限。在学校持有专利且未作有效授权、赋权或转让时，陈某不能自行将其作为个人财产出资。应核查授权、代理及交易材料，分别判断合同责任与权利变动，不能笼统宣布所有相关合同当然无效。 | 《专利法》第6条第1款：单位享有职务发明权利。《民法典》第847条第1款：有权的法人或非法人组织可以就职务成果订立技术合同。《促进科技成果转化法》第19条第1款、第2款：须依与单位的协议转化，不得侵占职务成果及资料、数据。 |
| 11. 公司登记了陈某25%股权，是否等于已合法取得专利 | 不等于。陈某取得公司股权与公司取得专利是两个法律事项。专利转让须有书面合同并依法登记，自登记之日起生效；还须核查处分权限。不能只凭公司章程、估值或股东名册认定学校专利已经合法转移。 | 《专利法》第10条第3款：专利申请权、专利权转让的书面合同、登记和生效规则。《专利法》第6条第1款：审查转让人有无相应权利基础。 |
| 12. 学校能否自主决定作价投资并确定800万元价格 | 学校依法可以自主决定转让、许可或作价投资，但自主决定不等于省略校内授权、定价、公示和适用的国有股权管理程序。800万元应有交易及市场依据，不能仅以陈某与投资者已达成一致视为学校认可。 | 《促进科技成果转化法》第18条：国家设立高校可自主决定转让、许可、作价投资；可通过协议定价、挂牌、拍卖等方式定价；协议定价须在单位公示成果名称和拟交易价格。 |
| 13. 学校主张作价投资收益最终全部归学校，不给团队分配 | 不符合国家设立高校适用的法定奖励要求。“收入留归单位”不能解释为不给贡献人员奖励。对该校，即使已有制度或协议，也应符合第45条规定的底线；省级要求更高的，还应适用更高标准。 | 《促进科技成果转化法》第43条：收入留归单位，但须先依法给予奖励报酬；第44条：规定制度、协议及制定公开要求；第45条第1款第（二）项、第2款：作价投资从形成的股份或出资比例中提取不低于50%，国家设立高校约定或规定的标准也须符合该底线。 |
| 14. 陈某取得25%公司股权是否属于应得的法定奖励 | 不能直接等同。若专利经合法安排形成25%公司股权，法定奖励基数是这25%，团队最低应获其一半，即公司总股权12.5%。法律没有规定陈某个人当然取得全部25%，也没有规定团队直接取得公司总股权50%。外部资本75%不是学校的分配份额。 | 《促进科技成果转化法》第45条第1款第（二）项、第2款：奖励基数为该成果形成的股份或出资比例，且适用于学校的合法制度、协议。个人取得股权仍须与《专利法》第6条及合法转化程序衔接。 |
| 15. 原报告建议“团队60%、学校40%”如何理解 | 这是建议协商比例，不是法律统一规定。以专利形成的25%为基数，团队取得公司15%、学校取得公司10%。如进一步假设团队内部陈某占80%、两学生各10%，则分别为公司12%、1.5%、1.5%；内部权重仍须依据真实贡献确认。 | 《促进科技成果转化法》第44条允许依法规定或约定奖励方式、数额和期限；第45条设定高校最低要求。“60%”及示例内部比例属于方案设计，不能冒充法定比例，也不能忽略其他重要贡献人员或更高的省级标准。 |
| 16. 学校保留专利，许可陈某公司使用；陈某要求优先受让 | 可以依有效协议选择保留权属、许可实施，并约定入门费、提成和查账；许可净收入的团队奖励同样应守法。学校依法转让职务技术成果时，完成人可在同等条件下优先受让，但不是无偿取得，也不是对任何交易当然享有否决权。 | 《促进科技成果转化法》第18条、第19条第1款及第45条第1款第（一）项、第2款：许可、协议转化及许可奖励底线。《民法典》第846条：价款、使用费、提成和查账；第847条第1款：同等条件优先受让。 |

## 三、教师创业、实验室限制与资源费用

| 主要行为或争议事项 | 本案认定及适用条件 | 法律条款或其他规范及对应规则 |
| --- | --- | --- |
| 17. 陈某未经审批成立、经营创业公司 | 应区分单纯持股、实际兼职任职、兼职创业和离岗创业。对依法应经单位同意的兼职、在职创业或离岗创业，未履行程序原则上存在人事管理问题；但不能仅凭公司成立就一概认定违法。普通教师是否兼具领导干部身份、当时适用的省级和校内制度，也须核查。 | 《关于支持和鼓励事业单位专业技术人员创新创业的指导意见》（人社部规〔2017〕4号）中关于兼职创新、在职创办企业及离岗创业的规定；相关省级实施规则、合法有效的学校人事制度及聘用合同。此项主要属于人事政策与内部合规判断，不能以《专利法》第6条直接认定“创业未经审批违法”。 |
| 18. 学校暂停陈某全部实验室使用权限 | 不能仅凭专利争议即认定全面停用合法。学校有依法管理校产的权限，但应证明具体的商业占用、安全、保密等风险，核查制度、合同依据及作出措施的权限、范围、期限和复核机制，并保障正常教学科研。管理权限不等于无限制停用或借投诉实施报复的权限。 | 《高等教育法》第38条、第41条第1款第（一）、（二）、（五）项：学校财产管理、规章制定、组织科研和校产保护的权限基础；具体措施仍须对照适用制度、合同及事实审查。这些条文没有直接规定“发生权属争议即可全面暂停实验室”。如违反有效聘用合同，另结合《民法典》第509条第1款等审查履约责任。 |
| 19. 学校要求补缴研发期间的“资源占用费” | 不能因认定职务发明，就自动生成个人欠费。执行学校任务的正常设备使用，不应在争议后追溯改为陈某个人有偿使用。应先查实际使用者、时间、用途及事先协议；职务成果的权属规则本身不是收费依据。 | 《专利法》第6条规定的是权属，不直接设定“资源占用费”。确有合法服务或使用协议的，依《民法典》第465条、第509条审查合同效力和履行；仅援引学校资产管理权，不能替代收费请求的具体法律基础及金额证据。 |
| 20. 公司成立后，未经允许额外占用学校设备、材料或场地 | 如查实额外商业使用，可依有效合同主张费用；无合同的，须按具体事实审查不当得利返还或侵权损害赔偿等请求是否成立。不得把不同请求权自动混同，不得临时创设惩罚性费用，也不得将同一投入重复计费。 | 《民法典》第509条第1款：依约履行；第985条：无合法根据获利时的不当得利返还，须满足法定要件并注意例外；第1165条第1款：过错侵害权益并造成损害的赔偿责任。三者对应不同事实基础，不代表学校可以任意选择名称收费。 |

## 四、使用本表时应特别区分的事项

| 容易混淆的事项 | 正确区分 |
| --- | --- |
| 发明人资格与专利权归属 | 作出创造性贡献决定发明人资格；任务、资源条件及有效协议决定职务归属。共同发明人不必然是共同专利权人。 |
| 授权奖金与转化收益奖励 | 前者对应获得专利授权，后者对应实施、转化及其收益；不能以一次授权奖金替代应有的转化奖励。 |
| 学校自主处置与教师个人处分 | 自主处置权授予学校，不等于每名发明人可以代表学校处理专利。创业获准也不替代专利处分授权。 |
| 合同责任、专利登记与股权登记 | 三项分别核验；公司取得股东、合同签订或者账面记载，均不能单独替代专利权转移的登记及处分权限审查。 |
| 法律规定、政策要求与协商建议 | 法律条文决定相应权利及底线；人事政策、合法校规补充人员与资源管理；“团队60%”“学生各10%权重”等只是建议，必须明确标示，不能当作法定结论。 |

**认定材料清单：**岗位聘用合同、项目任务书、纵横向项目合同、实验与设备使用记录、资金及材料凭证、专利权利要求和登记簿、学生参与协议与原始技术记录、学校已公布的人事及转化制度、出资协议、公司章程及股东名册。缺少相应材料时，应保留条件性结论，而不是以学校或教师单方说法替代事实查明。

**适用范围说明：**本表没有预设某一省份的提高奖励标准或职务成果赋权试点适用于该校；存在更高层级或更有针对性的适用规定时，应补充核验。主要条文编号和版本与原报告保持一致。
